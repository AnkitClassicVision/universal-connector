# Deliverable: 05n-carry-skills

This is the definition of done for the maker. It says what good looks like.
It does not say how the work is tested. Keep tests out of this file.

## Hand in

`carry.md`, or `skipped.md` if the skills plan carries nothing.

## Format

`carry.md`: Yes (who, when); then a table with one row per skill and target: Skill, Source folder, Target harness, Target folder, Link or copy, Key-shape scan result, Listed in the harness (yes or no), Rollback (the command that removes the link or copy).

## Must be true

- Only skills of class `portable-instructions` that the person chose were carried.
- No existing folder was overwritten.
- Every carried skill passed the key-shape scan before it was carried.
- Each row says whether the harness lists the skill.
- No value appears anywhere.

## Out of scope

- Editing a skill's content.
- Carrying a skill that wraps an outside API; that became a connection in the plan.
